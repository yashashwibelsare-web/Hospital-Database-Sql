Hospital Database Management System (SQL)
Project Overview
The Hospital Database Management System is an SQL project developed to organize and manage hospital information. It stores details about doctors, patients, medicines, surgical items, appointments, and prescriptions in a single database.
Tools Used
•	MySQL
Database Details
•	Database Name: hospital_db
•	Tables: Doctors, Patients, Medicines, Surgical Items, Appointments, and Prescriptions.
Key Features 
•	Created tables and inserted sample hospital records.
•	Modified table structures using ALTER TABLE.
•	Retrieved and sorted data using SQL queries.
•	Used aggregate functions such as COUNT () and AVG ().
•	Applied GROUP BY and HAVING to summarize data.
•	Used joins to retrieve related information from multiple tables.
•	Analyzed medicine prices, expiry dates, appointments, and prescriptions.
Learning Outcomes
Through this project, I gained practical experience in database management and writing SQL queries. I learned how to filter, sort, and analyze data, use aggregate functions, and join multiple tables. This project improved my understanding of how databases help manage hospital information efficiently.
Project File
 This project includes SQL queries for creating tables, inserting data, modifying tables, and practicing different SQL operations.
